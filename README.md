# NEDVI OS

Enterprise application foundation built with Next.js 15, TypeScript, Tailwind CSS, and the App Router.

## Development

Install dependencies with npm:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

## Structure

- `src/app`: App Router routes, layouts, and global styles
- `src/components`: Shared presentation components
- `src/config`: Application configuration
- `src/features`: Domain-oriented feature modules
- `src/hooks`: Shared React hooks
- `src/lib`: Framework-agnostic utilities
- `src/services`: External systems and data access
- `src/types`: Shared TypeScript types
